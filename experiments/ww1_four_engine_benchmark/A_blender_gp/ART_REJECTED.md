# ART REJECTED — do not use in benchmark deliverables

The initial native motion gate (`evidence_gate_contact.png` and
`A_BLENDER_GP_NATIVE_GATE_5S.mp4`) verified only that Blender 4.5.14 can create,
keyframe, save and render Grease Pencil v3 objects on this Apple Silicon host.

It failed the benchmark art direction because the character was primitive,
under-designed and too dark. The gate is retained only as technical evidence.
No geometry, frames, or visual design from this gate may be reused in any final
60-second render.
