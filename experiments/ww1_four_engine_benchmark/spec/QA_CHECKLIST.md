# Production acceptance checklist

- [ ] 4 independent pipelines checked for availability, version and native scene creation
- [ ] Each completed engine saves editable native project with animated keys and frames
- [ ] Native render logs and reproducible invocation preserved
- [ ] Actual character animation: hop/contact, helmet catch, cup grip, duck impact, ladder climb
- [ ] Five frames at each action pose show evolving CHARACTER geometry/pose, not global transform
- [ ] Cohesive designed backgrounds, line art, lighting and character identity, no placeholders
- [ ] Rain, mud displacement, rat, mug steam, shell light/dust, letter movement and ladder
- [ ] Exactly 1800 frames at 30fps, frame size 1080x1920, output H.264 yuv420p
- [ ] Shared identical full narration and mastered mix across every variant
- [ ] Exact word-aligned karaoke subtitles legible and clear of action/UI safe areas
- [ ] Subtitles correspond EXACTLY to spoken words, no generic 1-second blocks
- [ ] ffprobe video and audio tracks pass; no silence/dropouts/clipping or bad cuts
- [ ] Wall time and memory actually measured; null is preferred to speculation
- [ ] 8-scene contact sheet and 6 critical action comparisons visually inspected
- [ ] 7–10 shorts/week claim conditional on evidenced preparation effort, NOT assumed
- [ ] No engine chosen automatically; user's artistic selection required
