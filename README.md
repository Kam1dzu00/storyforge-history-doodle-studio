# History Doodle Studio

Local Apple Silicon desktop application that turns an English history brief or completed narration into a narrated 16:9 History Doodle video. Runtime is fully local: Qwen through MLX-LM, FLUX.2 Klein through MFLUX, Kokoro voice, MLX Whisper timestamps, and FFmpeg rendering.

Run `setup.command` once, then open `HistoryDoodle Studio.app` or `Start HistoryDoodle Studio.command`.
